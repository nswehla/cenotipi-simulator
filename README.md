# Cenotipi simulator

**Live: https://nswehla.github.io/cenotipi-simulator/**

Interactive 3D simulator of the **Cenotipi** art installation — a cenote inside a tipi, built
for Chillits 2026. Drag to orbit, scroll to zoom, use the View buttons (including a
first-person Walk mode), and play with the vines, LED patterns, fog, and lighting.

This is a deploy target: `index.html` is pushed here from the private planning repo whenever
the simulator changes. No development happens in this repo.
